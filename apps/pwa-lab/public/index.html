Pingo Lab

Protótipo descartável para testar o Pingo como PWA no celular. Nada aqui é o app de verdade.

1. Instalação e armazenamento

Se o botão não aparecer: menu ⋮ do Chrome → Instalar app (não "Adicionar atalho").

2. Compartilhar → Pingo

Abra o WhatsApp, segure uma mensagem (ou foto, PDF, nota de voz) → Compartilhar → Pingo Lab. Faça com o app fechado (deslize para fora dos recentes) e depois com ele aberto.

3. Lembrete com o app fechado (push)

Depois de agendar: feche o app, bloqueie a tela e espere. Quando chegar, toque em Feito ou Adiar (o resultado vai para o meu terminal).
